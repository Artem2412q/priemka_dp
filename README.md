# Дистанционная приёмка V3

Это новая версия сайта, построенная только под мастер-шаблон:
- template_id: `dp.checklist.acceptance`
- template_version: `v.05/01-PILOT.2`
- schema_version: `1.2-pilot`
- SKU: `12`
- layout: `12 SKU, все позиции видны сразу`

## Запуск
Windows: `START.bat`.
macOS/Linux: `START.command` или `python3 start_server.py`.

## Принцип экспорта
В проекте лежит единственный `template.xlsx` — присланный V3. При выгрузке сайт открывает именно его, сразу раскрывает предусмотренные в V3 товарные строки 1–12 и заполняет исходные ячейки. Формулы и связи V3 не пересоздаются: позиции 6–12 используют уже предусмотренные формульные связи с попозиционными блоками 6–12.

Старая схема, старый template.xlsx, old-template.xlsx и совместимость со старым чек-листом отсутствуют.

## Новые пункты разрушающего контроля
- 8.0.1 «Тара обнулена на весах» — Да/Нет, без тайм-кода.
- 8.0.2 «Отобранные единицы для разрушающего контроля взвешаны — не менее 2% от выборки» — Да/Нет, без тайм-кода.

## Хранение
Рабочие приёмки сохраняются в localStorage браузера. Одновременно до 5 приёмок, в каждой до 12 SKU.


## Изменение 03.09.2026 — фиксированные 12 SKU
В верхней товарной таблице строки 5–16 теперь всегда видимы. Схема раскрытия 5+5+2 больше не используется. Каждая из 12 товарных строк связана со своим попозиционным блоком чек-листа J…CI и имеет одинаковые формулы/правила заполнения.
