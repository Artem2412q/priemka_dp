# Magnit DP · NEXT

## v97 — товарные позиции без фиксированного лимита

- Убран лимит 12 товарных позиций в интерфейсе, плане РЦ и импорте из АРМ.
- Заявка переносится в приёмку целиком независимо от количества ТП.
- Новая Excel-выгрузка создаётся динамически в браузере, масштабируется вертикально и сохраняет все позиции в одном XLSX.
- Лист `Чек лист_ДП_Отчет` содержит общую таблицу всех товарных позиций.
- Лист `Контроль_по_позициям` содержит подробный контроль каждого SKU.
- Лист `Дефекты` содержит дефекты всех товарных позиций.
- Старая фиксированная форма сохранена только как legacy-совместимость.


## v96 — План РЦ на день

После авторизации пользователь попадает на главный экран. Можно сразу открыть онлайн-приёмку или выбрать свои РЦ и загрузить Excel-выгрузку АРМ. Система группирует строки по номеру заявки, считает товарные позиции, показывает ожидаемый объём на текущую дату и позволяет запускать приёмку прямо из плана. Ручные заявки также поддерживаются.

# Магнит · Дистанционная приёмка

Версия **NEXT 90** — переработанный интерфейс дистанционной приёмки с персональными рабочими сессиями ДП, журналом смены и поддержкой до 30 параллельных РЦ.

## Запуск

Распакуйте архив целиком. На Windows запустите **START.bat**, на macOS — **START.command**, на Linux — `bash run.sh`. Локальный сервер использует Python 3 и не требует установки дополнительных модулей.

Для автономной работы можно открыть **index.html** напрямую в современном браузере. Основная логика, темы, Excel-библиотеки и шаблоны находятся внутри проекта. Для стабильной работы импорта/выгрузки предпочтителен запуск через START-файл.

Для статического хостинга замените содержимое проекта всеми файлами из папки проекта, включая `assets`, `vendor`, Excel-шаблоны и JS/CSS. Сборка через npm не требуется.

## Что изменено в NEXT 90

### Персональная сессия вместо старого логина/пароля

- Вход выполняется только по **ДП (ID)** и дате начала рабочего дня.
- Пароль и общий системный логин удалены.
- ДП (ID) автоматически подставляется во все уже открытые и новые чек-листы.
- Поле ДП (ID) защищено от случайного ручного изменения как в стандартном, так и в операционном режиме.
- При импорте из АРМ ДП (ID) также берётся из текущей персональной сессии.
- При первом входе отображаются условия работы и правила конфиденциальности.

> Важно: проект остаётся статическим. Вход только по ID является идентификацией пользователя внутри приложения, а не серверной проверкой личности. Для строгого контроля доступа потребуется корпоративный backend/SSO.

### «Моя смена»

Добавлен отдельный шестой раздел **«Моя смена»**:

- дата рабочего дня;
- необязательная отметка «Рабочий день закончен»;
- количество выгруженных чек-листов;
- суммарное количество товарных позиций;
- число уникальных РЦ и поставщиков;
- журнал: номер заявки, РЦ, поставщик, количество ТП и время выгрузки;
- отдельная Excel-выгрузка итогов смены.

Запись попадает в журнал после успешной выгрузки чек-листа. Повторная выгрузка того же рабочего пространства обновляет существующую запись и не увеличивает счётчик искусственно.

### До 30 РЦ одновременно

Лимит параллельных рабочих пространств увеличен с 5 до **30 РЦ**. Переключатель переработан под большую нагрузку: карточки РЦ выводятся сеткой, имеют собственный прогресс и адаптируются под планшет/телефон.

### Новый интерфейс

- Новый визуальный слой **Magnit Next 2026**: фирменный красный, графитовая навигация, светлая рабочая область и более строгая информационная иерархия.
- Полностью переработаны экран входа, верхняя панель, рабочая навигация, карточки, формы, кнопки, переключатель РЦ и страница смены.
- Интерфейс адаптирован под широкие экраны, ноутбуки, планшеты и телефоны.
- Поля, состояния, прогресс и действия получили более заметную визуальную иерархию для быстрого заполнения в течение смены.
- Системная настройка `prefers-reduced-motion` поддерживается.

### Темы

Добавлены новые темы:

- **Magnit Next 2026** — основная;
- **Magnit Air** — более лёгкая светлая;
- **Magnit Night** — тёмная для вечерней работы.

Существующий редактор тем и дополнительные пресеты сохранены.

### Анимационный ролик

«Путь свежести» обновлён как короткий локальный SVG/CSS/JS-ролик:

**поставщик → прибытие на РЦ → контроль качества → допуск в сеть**.

Обновлены переходы сцен, титры, прогресс, фирменные акценты и управление воспроизведением. Ролик не требует интернет-соединения или видеофайлов.

## Сохранённая бизнес-логика

Сохранены пять основных разделов приёмки, 11 шагов контроля, Brix, цвет/плотность, групповая и индивидуальная проверка товаров, товарные позиции без фиксированного лимита, дефекты и некалибр, расчёты масс, тайм-коды, заметки, импорт из АРМ, прогрессивное время архива, старая и новая формы Excel.

Новая рабочая Excel-форма генерируется динамически и переведена на масштабируемую структуру без фиксированных 12 SKU: общая таблица товаров, подробный контроль и дефекты хранятся на отдельных листах одного XLSX. Старая фиксированная форма сохранена только как legacy-шаблон.

## Хранение данных

Рабочие данные, персональная сессия и журнал смены хранятся локально в браузере. Состояние предыдущей версии workspace мигрируется через legacy-ключ. Для переноса данных между компьютерами/профилями используйте резервную JSON-копию в разделе «Итоги».

Для NEXT 90 выполнены:

- синтаксическая проверка `app.js`, `theme-studio.js` и `journey.js`;
- браузерный прогон входа по ДП ID без пароля;
- проверка автоподстановки и `readonly` для ДП ID;
- открытие отдельной страницы «Моя смена»;
- создание 30 параллельных РЦ и блокировка 31-го;
- проверка новой темы Magnit Next 2026;
- проверка политики без упоминания старого пароля;
- браузерная проверка журнала смены с двумя заявками;
- фактическое формирование дневного файла `Смена_<ДП ID>_<дата>.xlsx` через ExcelJS без runtime-ошибок.

## Основные файлы

- `index.html` — структура приложения и персональный вход.
- `design.css` — базовые стили проекта.
- `next-design.css` — новый слой интерфейса NEXT 90.
- `app.js` — бизнес-логика, рабочие пространства, сессии ДП и журнал смены.
- `theme-studio.js` — темы оформления.
- `journey.html`, `journey.css`, `journey-next.css`, `journey.js` — анимационный ролик.
- `experience.js` — анимация выгрузки и просмотр ролика.
- `template.xlsx` — эталон новой масштабируемой структуры Excel; рабочая новая форма формируется динамически через ExcelJS. `old-template.xlsx`, `old-template-data.js` — legacy-форма на 12 SKU.
- `arm-import-worker.js` — обработка импорта АРМ.
- `start_server.py` — локальный сервер.

### Ручной импорт чек-листов в смену
На странице **«Моя смена»** готовые файлы `.xlsx` можно перетащить в блок **«Добавить готовые чек-листы из Excel»**. Система локально считывает номер заявки, РЦ, поставщика и количество товарных позиций и добавляет запись в журнал выбранной даты. Повторная заявка обновляется без дублирования.
