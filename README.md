# Магнит · Дистанционная приёмка

Обновлённый интерфейс «Свежесть», версия 80.

## Запуск

Распакуйте архив целиком. На Windows откройте **START.bat**. На macOS — **START.command**, на Linux — `bash run.sh`. Локальный сервер использует Python 3, дополнительные модули не нужны.

Без Python можно открыть **index.html** в современном браузере: интерфейс, сохранение данных и формирование Excel работают локально. Все шрифты, иллюстрации и библиотеки включены в папку проекта. Логин и пароль сохранены из исходной версии.

Для существующего статического хостинга замените содержимое проекта всеми файлами из папки `priemka_dp-main`, включая `assets` и `vendor`. Сборка через npm не требуется.

## Новый дизайн

- Полностью обновлены начальный экран, навигация, все пять разделов и 11 шагов проверки.
- Светлая рабочая область, глубокая бордовая навигация, новая типографика и плавные переходы; отдельная компоновка для телефона и планшета.
- «Путь свежести» — 24-секундный анимационный ролик: урожай → РЦ → контроль качества → полки «Магнита». В сцене проверки допуск открывается после успешного контроля. Ролик сделан средствами SVG/CSS/JavaScript, работает локально и без звука.
- Ролик можно поставить на паузу, переключить сцену и повторить. Повторный просмотр доступен из боковой панели или меню на телефоне.
- При выгрузке Excel показываются этапы подготовки, заполнения и сохранения. Завершающая анимация появляется после передачи готового файла браузеру. До этого момента выгрузку можно отменить.
- Учтена системная настройка уменьшения движения: ролик не запускается автоматически, переходы сокращены.

## Сохранённые возможности

Пять разделов: приёмка, товары, проверка, дефекты и итоги. Сохранены все 11 шагов, вопросы и условия показа Brix, цвета и плотности; общая и индивидуальная проверка товаров; до 12 товаров и пяти независимых приёмок; дефекты, расчёт массы, время, заметки, темы оформления, оперативный режим и импорт из АРМ.

Автосохранение и существующие ключи данных оставлены прежними. Сохранены новая и старая формы Excel, формулы, стили, объединения и привязки ячеек. Файлы `template.xlsx`, `old-template.xlsx` и их встроенные копии не менялись.

Данные хранятся в браузере. Чтобы перенести заполненные приёмки на другой компьютер, домен, порт или профиль браузера, заранее скачайте JSON-копию в разделе «Итоги» и восстановите её в новом месте. Замена файлов на прежнем адресе в прежнем профиле использует существующие сохранения.

## Проверка совместимости

Проверены вход и обязательные поля, все 11 шагов, общая проверка, дополнительные показатели, дефекты, расчёты, заметки, несколько приёмок, оперативный режим и сохранение темы.

Обе формы Excel выгружены исходной и обновлённой версией на одинаковом наборе из 12 товаров, включая время через полночь. XML-содержимое данных, формул, оформления и структуры совпадает. При сравнении исключены только динамические метаданные создания файла.

Дополнительно проверены автономный запуск и экспорт без сервера, отмена выгрузки, последовательность сцен ролика, уменьшение движения и отсутствие горизонтального переполнения на ширинах 320, 820 и 1920 пикселей. Всего пройден 21 сценарий проверки.

## Основные файлы

- `index.html`, `design.css` — новая структура и оформление.
- `journey.html`, `journey.css`, `journey.js` — начальный анимационный ролик.
- `experience.js` — анимация выгрузки, просмотр ролика и доступность интерфейса.
- `app.js`, `theme-studio.js` — приложение и выбор оформления.
- `template.xlsx`, `old-template.xlsx`, `schema.js`, `exporter.js` — исходные шаблоны и экспорт.
- `arm-import-worker.js` — исходная обработка импорта АРМ.
- `start_server.py` — исходный локальный сервер.

Исторические `CHANGELOG_V3.txt` и `V3_MAPPING.md` оставлены для справки. Лицензия включённого шрифта Manrope находится в `assets/fonts/OFL.txt`.
